请基于以下输入参数生成一个电商数据轻量看板分析结果：

### 输入参数 ###
1. 数据源类型：
   - 可选值：微信订单、抖音小店、快递 100
2. 时间段：
   - 用户选择日期范围
3. 场景预设：
   - 可选值：场景 A（快速周转）、场景 B（稳定增长）、场景 C（成本优化）

### 输出要求 ###
1. **每日发货量**：
   - 使用时间线展示每天的发货数量。
2. **复购率**：
   - 使用表格展示每天的复购率。
3. **客单价**：
   - 使用卡片展示平均客单价和最高客单价。

### 注意事项 ###
1. **普适性**：工具应适用于各类电商平台和场景，不依赖于特定公司或产品。
2. **实用性**：分析结果应能够帮助用户了解运营状况并做出决策。
3. **数据驱动**：如果用户上传了数据，优先基于这些数据进行分析；否则使用内置场景预设。
4. **输出格式**：输出应为结构化的 JSON 对象，包含以下字段：
   - dailyShipments：数组，每个元素包含 date 和 quantity 字段。
   - repeatRate：数组，每个元素包含 date 和 rate 字段。
   - unitPrice：数组，每个元素包含 average 和 highest 字段。

### 示例输出 ###
```json
{
  "dailyShipments": [
    { "date": "2023-10-01", "quantity": 100 },
    { "date": "2023-10-02", "quantity": 150 },
    { "date": "2023-10-03", "quantity": 200 }
  ],
  "repeatRate": [
    { "date": "2023-10-01", "rate": 10 },
    { "date": "2023-10-02", "rate": 15 },
    { "date": "2023-10-03", "rate": 20 }
  ],
  "unitPrice": [
    { "average": "¥ 100", "highest": "¥ 200" }
  ]
}
```
